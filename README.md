# Akpe

**Akpe** ("gratitude" in Eʋegbe) is a free presentation app for Ghanaian churches:
hymns, Bibles, announcements and the whole order of service on the projector, in our
own languages, with phones following along on the church's Wi-Fi. It works with no
internet at all.

Made by the Psirdematica DEV team. This repository holds the installers only; the
source code is private.

## Download

Open the [latest release](https://github.com/Psirdem/akpe-builds/releases/latest) and
download the file for your computer:

| Computer | File |
|---|---|
| Windows 10 or 11 | `Akpe_<version>_x64-setup.exe` |
| Ubuntu (any recent version) | `Akpe_<version>_amd64.AppImage` (updates itself) |
| Ubuntu, installed as a package | `Akpe_<version>_amd64.deb` |

- **Windows:** if a blue "Windows protected your PC" box appears, choose
  **More info → Run anyway**. Akpe is not yet signed with a paid certificate.
- **Ubuntu AppImage:** right-click the file → Properties → Permissions → allow running
  as a program, then double-click it.
- **Updates:** open Akpe → About → **Check for updates**. A `.deb` is updated by
  installing the newer `.deb`.

You may share these installers, unchanged and free of charge, with other churches,
for example on a USB drive.
